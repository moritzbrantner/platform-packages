# @moritzbrantner/storytelling

Interactive storytelling models, React players, and Remotion or Three-friendly rendering helpers.

## Main APIs

- `defineStory(story)` / `validateStory(story)` / `resolveStoryPath(story, options)` / `buildStoryTimeline(story, options)`
- `StoryPlayer`, `StoryControls`, `StoryScroller`, `StoryProgress`, and `StoryMinimap`
- `createStoryRendererRegistry(...)` / `getStoryStageProps(...)`

## Notes

- The package also exports story model types for React, Remotion, and Three.js based renderers.
