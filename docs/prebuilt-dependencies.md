# Prebuilt dependencies for isolated checkouts

Issue #132: Renovate checks out only platform-packages. It has neither a sibling rust-packages repository nor a Rust/WASM compiler, so its ordinary Bun lockfile update must not build source dependencies.

## Installation contract

vendor/prebuilt contains three deliberately checked-in, installable packages: dense-data-wasm, text-core-wasm and Maps. The first two retain the source adapters and compiled WASM; Maps retains the full built ESM, type declarations, CSS and WASM. Only the producer build scripts and devDependencies are removed from their consumer-facing manifests. Their runtime identity, exports, version and runtime dependencies are unchanged.

scripts/prebuilt-source-pins.json fixes both upstream revisions at immutable 40-character Git commits. vendor/prebuilt/provenance.json records all resulting files and SHA-256 hashes. CI checks exact identity, file inventory, export presence and hashes before running Bun. Reviewed artifacts are installed by local file: dependencies, without a mutable registry or sibling path. The hashes protect against accidental changes to generated bytes; review of the upstream SHA and producer code remains necessary to authenticate the build.

## Refreshing

1. Review and change the upstream Git SHA in scripts/prebuilt-source-pins.json.
2. In an explicit Rust-capable builder using Bun 1.4.2, run bash scripts/refresh-prebuilt-dependencies.sh. It fetches exact upstream commits in scratch directories and uses the existing pinned producer build scripts.
3. Run bun install to regenerate bun.lock, then node scripts/verify-prebuilt-dependencies.mjs and bash scripts/verify-isolated-install.sh.
4. Run Fast Validation, review built artifact/hash/lockfile changes together, and merge only on green results.

The Refresh Prebuilt Dependencies GitHub workflow can perform the refresh and commit generated files to a dedicated branch. This is intentionally separate from Renovate and ordinary Fast Validation. Do not hand-edit files in vendor/prebuilt. Maps updates require an explicit source-pin refresh rather than a silent git digest update.

## Renovate acceptance

scripts/verify-isolated-install.sh creates an archive of Git HEAD in a scratch directory, masks Rust executables with failing scripts, makes a real registry dependency change, regenerates bun.lock, runs frozen installation, and exercises both Rust-derived WASM packages and the Maps WASM export. Normal Fast Validation runs independently against the committed lockfile. No part of the test writes the real dependency tree.
