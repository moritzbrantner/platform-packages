# Repository Rules

- When developing the app locally, run it in dev mode with `bun dev`.
- The app dev server must use port `8703`; treat `http://localhost:8703` as the default local app URL.
- Treat Clean Code principles as a repository-wide rule: prefer clear naming, small focused units, single-purpose functions/components/modules, low duplication, explicit boundaries, and tests/docs for behavior that is not obvious from the code itself.
