# @moritzbrantner/remotion

Remotion helpers for rendering temporal map tracks as frame-synced map scenes.

## Main APIs

- `getRemotionMapTimeAtFrame(options)`
- `useRemotionMapTime({ tracks, ...timing })`
- `RemotionClusteredMap` and `RemotionHeatMap`

## Notes

- This package depends on `@moritzbrantner/maps` and expects `remotion` as a peer dependency.
