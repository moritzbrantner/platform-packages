# @moritzbrantner/typescript-config

Shared TypeScript config presets for Node libraries, React libraries, and Next.js apps.

## Main APIs

- `@moritzbrantner/typescript-config/base.json`
- `@moritzbrantner/typescript-config/node.json` and `react-library.json`
- `@moritzbrantner/typescript-config/next-app.json`
