# @moritzbrantner/foundation-contract

Shared application roles, permissions, settings, profile, notifications, and admin table contracts.

## Main APIs

- `appPermissionKeys` and `defaultRolePermissionAssignments`
- `normalizeAppSettings(value)` / `formatDatePreview(date, settings, locale)`
- `getVisibleProfiles(...)`, `createNotificationsPageData(...)`, and `validateReportProblemPayload(...)`
