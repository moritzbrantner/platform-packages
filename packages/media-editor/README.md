# @moritzbrantner/media-editor

Media timeline core utilities and a React timeline component for clip-based editing flows.

## Main APIs

- `MediaTimeline` and `defaultMediaTimelineHotkeys`
- `normalizeTimelineTracks(...)`, `moveTimelineClip(...)`, and `resizeTimelineClip(...)`
- `detectTimelineOverlaps(...)` / `getTimelineDurationMs(...)`

## Notes

- The package also exposes `@moritzbrantner/media-editor/core` and `@moritzbrantner/media-editor/react` subpaths.
