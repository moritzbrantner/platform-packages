# @moritzbrantner/card-games

React card-table primitives for playing cards, hands, fans, and suit formatting.

## Main APIs

- `PlayingCard`, `CardFan`, `CardStack`, `CardTable`, and `PlayerHand`
- `getSuitSymbol(suit)` / `getSuitName(suit)`
- `formatCardLabel(rank, suit?)`

## Notes

- This package ships UI primitives only; game rules and state management belong in higher-level packages or apps.
